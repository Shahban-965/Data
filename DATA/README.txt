SHAKEEL NETWORKING — PORTABLE DATABASE

This folder contains the live database as readable UTF-8 JSON files.
Keep this entire DATA folder beside the portable application executable.
To move to another PC, close the app, safely eject the USB, then copy the
whole application folder (including DATA) to the other computer.

Do not edit JSON files while the application is running.
Do not remove files manually. Use the app's backup/restore tools.
Automatic previous-version snapshots are stored in DATA/backup/YYYY-MM-DD.
Manual full snapshots are stored in DATA/backup/manual-<timestamp>.
